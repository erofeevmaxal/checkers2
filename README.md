# Инструкция по запуску проекта

## требования
-Python 3.7 или выше
-установалеенная библеотека pygame

## установка библеотеки
1) перейдите в директорию проекта: cd /путь к проекту
2) установите библеотеку: pip install pygame

## запуск программы
1) убидитесь что находитесь в корневой директории 
2) запустите основной файл main.py

## структура проекта
assets/: Папка с изображениями

checkers/: Папка с модулями игры в шашки.

__init__.py: Инициализация пакета.

board.py: Логика игрового поля.

constants.py: Константы игры.

game.py: Основная логика игры.

piece.py: Логика фигур.

main.py: Основной файл проекта.

## правила игры

https://ru.wikipedia.org/wiki/Русские_шашки

## управление

-выбор ход осуществляется на LKM:
1) выберите фишку
2) выберите один из возможных отмеченных ходов
3) если ходов нет, значит, ход нарушает правила игры, попробуйте выбрать другую фишку
